# 问题四：实时波动电价下的微网购电策略（初稿 v3）

> 版本：v3（2026-09-12 深夜，以 `results/q4_v3/README.md` 为准）。
> 配套代码 `scripts/q4_model_v3.py`（唯一入口）、独立核验

> （主方案 F_48）、`result4-3.xlsx`（主方案 G_48）。
> 评价期与问题二、三一致：2025-02-01~12-31 共 334 天。

## 一、问题重述（问题四部分）

外网电价实时波动（附件4 给出 2025 年每 10 分钟区间的实时电价）。在波动电价下
重新建立微网当天购电策略的数学模型，结合附件2 的负载与光伏实测、附件3 的
光伏预报、附件4 的电价数据，重新计算问题二（仅 0:00 制定计划购电策略）与
问题三（0:00 计划 + 6/12/18 时刻调整），分别保存到 result4-2.xlsx 与
result4-3.xlsx。

## 二、模型假设与信息口径

1. **电价揭示口径（因果）**：附件4 为区间实时价 $p_t$（元/kWh），只有已完成
   区间的价格可知：0:00 决策只知 $d-1$ 日及以前；6/12/18 调整决策另知当日
   已揭示前缀。题面未明示揭示方式，§7 给出"日前已知全天价"对照的量化。
2. **结算口径**：合同按实时价 $p_t$ 计费；调整对计划净额收 $0.5\,p_t$
   （口径 B，同问题三）；紧急购电 $5\,p_t$。
3. **设备与运行约束**：同附录 1（SOC∈[1200,10800] kWh，充放功率 5000 kW，
   效率 0.9，2025-01-01 0:00 初始 6000 kWh）。
4. **滚动时域口径（v3 新）**：每日 0:00 只提交**当日**合同；优化终点可延至
   次日 24:00，次日需求用**持久性预测**（当日预测平铺）估计，次日暂拟购电
   不提交、不产生任何费用。这是对 Q2/Q3"日循环 $E_H=E_0$"建模约定的放宽
   （附录 1 本身只要求 SOC 运行区间），按模型预测控制（MPC）解读与题意
   "当天购电策略"不冲突；可比性由年末终端归一化实验保证（§6.1、§6.5）。
5. **评价协议**：1 月共同预热（TOU + 代表日，E(1/1)=6000），评价期起点
   SOC=10800（两分支相同）；全部选参与诊断只用当期之前的数据。

## 三、附件4 电价数据的结构分析

| 事实 | 数值 | 建模含义 |
|---|---|---|
| 全年均值 | 0.7662 元/kWh，与附件1 TOU 均值完全相同 | TOU 是实时价的期望形状 |
| 全年逐区间均值与 TOU 的相关 | **1.0000** | $P_{d,t}=\ell_d\pi_t^{\mathrm{TOU}}+r_{d,t}$ 分解成立 |

| $p>1$ 元区间占比 / $p<0.2$ 元占比 | 27.45% / 0.57% | 高价频繁，紧急通道代价大 |

## 四、模型建立

### 4.1 价格缩放不变性（命题 4.1）

**命题 4.1** 把某决策点处价格预测 $\hat p$ 整体乘以正常数 $s$，计划 LP 与
调整 LP 的最优解集不变（目标对价格齐次一次，约束不含价格）。**推论**：
日水平预测误差不改变任何决策，决策只需要归一化形状。数值验证：
$1.37\times$TOU 与 TOU 的计划解逐位相同（最大差 = 0）。

### 4.2 因果价格预测（实证后仅保留 TOU 形状）

0:00 通道 $\hat r_t=a_0r_{d-1,t}$、日内两因子 OLS 通道均可改善价格预测精度，
但 §6.2 表明对费用无效或有害；主方案决策价取附件1 TOU 形状。
**v3 修复**：日内水平估计改为只用 τ 之前的前缀（正则化缩向 30 天先验），
并通过"扰动未来电价、预测不变"的因果测试（3 天 × 4 时刻，diff=0）。

### 4.3 价格加权风险裕量（PRM）与保护强度重校准

短缺的期望紧急代价被 $5p_t$ 放大，故把能量空间分位裕量按价格形状加权：
$$\hat N'_t=\hat N_t+(w_t-1)M_t^{(\beta+\delta)},\qquad
w_t=\operatorname{clip}\big((\hat p_t/\bar{\hat p})^{\lambda},0.5,2\big),$$
$w$ 由 0:00 决策价给出并整日冻结。Q2 分支最优 $(\lambda,\delta)=(1,0)$；
Q3 分支 $(0.8,-0.125)$——**两分支保护结构相反**：无追偿时全局裕量不可
替代；有调整兜底时全局裕量几乎全是成本，最优退化为"低全局裕量 + 高价
时段峰值保险"。

### 4.4 48 小时滚动时域（v3 核心升级）

v2 的计划 LP 强制 $E_H=E_0$（日循环），禁止储能跨午夜持有电量。v3 把优化
终点延到次日 24:00：

- **计划（0:00）**：对 $[p;\,p]$、$[\hat N;\,\hat N]$（持久性平铺）解
  288 区间 LP，末端约束 $E_{48h}=E_0$，只取当日 144 区间合同提交；
- **调整（6/12/18）**：对"今日剩余 + 次日"重解 LP，今日部分对计划净额
  收 $0.5p$ 附加费，次日暂拟购电免费不提交，末端约束次日末回到今日起始
  SOC。

信息上严格因果（次日只用持久性预测），规则上仍是"当天购电策略"
（每天只提交当天合同），但允许储能跨午夜优化配置。

### 4.5 执行与结算

must/max 尽限执行（同 Q2/Q3）；合同与紧急按实时价结算；调整净额附加
$0.5p_t$。执行规则在情景评分中原样使用（见 §6.4 选择器实验）。

## 五、模型求解与数值校验

- 因果测试：未来电价扰动下全部预测不变（diff = 0，3 天 × 4 时刻）；
- 全部 20 条轨迹通过审计：SOC 界 / 递推 / 平衡 / 功率 / 非负 / 跨日衔接
  $<10^{-7}$；
- **独立核验**（不导入任何调度代码，`q4_check_v3.py`）：账本独立复算
  （误差 $<10^{-6}$ 元）、9 个结果工作簿逐格比对（舍入 $<5\times10^{-5}$）、
  严格下界 ≤ 各配置费用，全部 PASS；
- 复现清单：输入数据与全部代码 SHA-256（`repro_manifest.json`）；
- 主方案为同年探索性选择，20 配置全量公布；两个在线选择器（只用历史
  费用/情景）也未超过固定参数（§6.4）。

## 六、结果分析

### 6.1 主方案结果

| 分支 | 主方案 | 总费用（万元） | 合同费 | 附加费 | 紧急费 |
|---|---|---|---|---|---|
| Q2 分支 | **F_48**（PRM λ=1 + 48h 时域） | **1438.2280** | 1395.11 | 0 | 43.12 |
| 对照 F_fixed（同参数 24h 版） | | 1449.3035 | 1405.64 | 0 | 43.66 |
| Q3 分支 | **G_48**（PRM λ=0.8, δ=−0.125 + 48h） | **1404.2431** | 1351.65 | 18.38 | 34.21 |
| 对照 G_fixed（同参数 24h 版） | | 1410.9389 | 1358.39 | 18.42 | 34.13 |
| 对照 G_base（Q3-B1 平移） | TOU 决策价 | 1420.9530 | 1383.81 | 16.15 | 20.99 |

**48h 时域的收益**：Q2 分支 −11.08 万、Q3 分支 −6.70 万；**终端归一化对照**
（12/31 强制 $E_{end}\ge10800$ 重跑最后一天）后为 −10.96 / −6.58 万——收益
不是年末库存差异伪影。机制：日循环强制每天傍晚把 SOC 拉回早晨水平，
低价夜间的充电能力被合同上限浪费；48h 时域允许跨午夜搬电，次日（按预测）
自然回到循环点，合同费相应下降（F 分支 1405.64→1395.11 万）。

### 6.2 消融与"可预测 ≠ 有价值"

| 配置 | 费用（万元） | 结论 |
|---|---|---|
| F_low / F_high（δ=∓0.05） | 1451.40 / 1456.09 | Q2 分支 δ 双向有害 |
| G_price（泄漏修复后的日内价格通道） | 1411.4533 | 仍 +0.51 vs G_fixed（关闭） |
| G_price_oracle（**同裕量政策**的价格全知） | 1403.2359 | 价格预知的真实价值 = **7.7030 万** |

附件4 残差可预测（隔日 0.64、日内 0.89），但因果价格通道对费用无效：
LP 最优解对小价格扰动分段常值。与问题三"MAE 改善 ≠ 费用节省"呼应。

### 6.3 $(\lambda,\delta)$ 网格与主方案选择（沿用 v2 结论）

Q3 分支轨迹：1420.95（G0）→ 1415.03 → 1413.23 → 1412.20 → 1411.64 →
**1410.94（λ=0.8, δ=−0.125，冻结）**；δ 是主杠杆，δ=−0.175 过深有界确认，
λ>0.8 按过拟合纪律关闭。Q2 分支 λ=1 为峰（1449.44 / **1449.30** / 1455.12）。
48h 时域叠加在冻结参数之上，未重新调参。

### 6.4 选择器实验（执行规则一致的情景/滚动择优）

| 配置 | 费用（万元） | 结论 |
|---|---|---|
| F_feedback（must/max 逐情景回放择优） | 1454.0639 | 劣于 F_fixed 1449.3035 |
| G_online（月度滚动择优，只用历史费用） | 1412.1401 | 劣于 G_fixed 1410.9389 |
| G_feedback（3 medoid 情景 + 情景内排程调整回放） | 1413.2445 | 劣于 G_fixed |

三个选择器都不含未来信息（历史窗口 / 历史费用），但仍未超过同年探索性
选定的固定参数——该选择方式已如实标注，在线择优方向关闭。

### 6.5 遗憾分析与严格下界

| 参照 | 费用（万元） | 口径 |
|---|---|---|
| **严格下界**（全期完美信息 LP，松日循环、自由末端） | **1277.9221** | 不可达参考（享自由末端+完美信息） |
| G_price_oracle（同政策价格全知） | 1403.2359 | 价格侧遗憾 7.70 万 |
| N_ORC（v2，负荷全知，24h 政策） | 1301.2464 | 负荷侧仍是主要遗憾源 |

主方案 G_48 距严格下界 126.32 万，其中可归属价格侧的仅 7.70 万（同政策
对照），**算力应继续投向负荷侧**。

### 6.6 v3 errata（对 v2 的三处修正）

1. **日内价格信息泄漏修复**：v2 日内残差用当天全部 144 个价格估计日水平
   （含未来区间）；v3 只用 τ 前前缀并通过因果扰动测试。修复后日内通道
   仍无效，方向结论不变但依据干净；
2. **情景 LP 终端罚未除以情景数修复**：v2 的 H0B 把末端罚放大约 30 倍。
   v3 修正并通过"复制情景目标不变"测试；情景规划方向改由执行规则一致的
   回放评分（§6.4）重新检验后再关闭；
3. **"价格预知价值 ≈ 0"撤回**：v2 的价格全知参照（1414.3723）用未重校准
   的裕量政策，主方案低于它不构成有效证明。同政策重算后价格预知的真实
   价值为 7.7030 万（§6.2）。

## 七、敏感性

- **价格揭示口径**：若"日前已知全天价"（G_price_oracle 口径），同政策费用
  1403.2359 万——口径切换最多值 7.70 万；
- **48h 持久性预测**：次日 = 当日预测平铺是明确声明的近似。已测**次日全知
  上界**（F_48o = 1435.2658 / G_48o = 1401.1517 万，非因果不可实施）：
  平铺距理论上限仅 2.96 / 3.09 万，因果次日预测最多收回其中一部分，
  该方向据此关闭；
- **终端归一化**：48h 收益在共同年末终端下保持（§6.1），不依赖年末库存
  处理。

## 八、局限与讨论

1. 价格揭示口径（区间完成后可知）是假设，题面未明示；
2. $(\lambda,\delta)$ 与 48h 时域均为同年探索性开发，20 配置全量公布，
   不是未触碰外部测试；
3. 48h 时域放松了 Q2/Q3 的日循环约定——附录 1 只约束 SOC 区间，但为保证
   与 Q2/Q3 数字可比，本文同时报告 24h 对照（F_fixed/G_fixed）与终端归一化
   实验；
4. 严格下界含自由末端优势（耗尽 9600 kWh 初始库存），主方案与它的差距
   不全是可消除遗憾。
