\section{模型评价与改进（问题一、二、三）}

\subsection{模型优点}

\begin{enumerate}
  \item 问题一模型为线性规划，可求全局最优且完全可解释；充放电互斥约束经命题保证松弛精确，无需整数变量；
  \item 问题二的三层结构将``不可预知的需求''与``可优化的计划''分离：预测层显式利用星期周期这一可解释信号（消融实验贡献 324.01 万元），计划层保持线性规划的可解性，执行层规则完全因果、可实现；
  \item 问题三的调整层把``计划购电量高于调整购电量按 $0.5p$、反之超出部分按 $1.5p$''这一条含分段的结算规则，化归为\emph{单个}线性规划（式~\eqref{eq:q3-adjust}），使合同重定仍可求全局最优、无需引入二元变量或分段逻辑；$2\times2$ 对照设计则把``信息''与``调整机会''两类改进的贡献分开计量，并量化出二者 9.62 万元的替代性重叠；
  \item 全部参数选取采用逐月 walk-forward 协议，严格排除数据泄漏；问题三的分档收缩系数 $\kappa_g$ 亦只用 $d$ 之前 30 天数据逐日重估，与问题二口径一致；
  \item 主方案紧急费用仅占 5.5\%，说明``预测＋分位裕量＋尽限执行''的组合在不对称惩罚下是有效的；问题三中``是否需要其他时刻预报''这一开放式问题通过实验而非直觉判定，给出了可复核的否定结论。
\end{enumerate}

\subsection{模型局限与改进方向}

\begin{enumerate}
  \item \textbf{冷启动与选参信息量}：预测器在 $d<30$ 时整体回退为代表日曲线，2 月首次选参仅能在 1 月 31 日单日的费用上区分候选；若改用其他冷启动规则，参数日程与费用都需重新核验；
  \item \textbf{网格边界未充分展开}：$\gamma=1.0$ 与 $N_{\mathrm{DOW}}=4$ 位于网格边界，补充扫描只表明``所考察的网格上未发现更优点''，不构成全局最优性结论；
  \item \textbf{预测器形式的选择依据有限}：曾尝试把星期偏差分别施加于负载与光伏两条通道，所得费用更高，提示``作用于净负载''是更有效的形式；但该比较仅在本文的网格与链路内进行；
  \item \textbf{问题三的结论受结算口径约束}：``不需要其他时刻预报''是在偏差对 0:00 计划计量、加价率 $0.5p$/$1.5p$ 的结算规则下得到的；本文仅考察了``全融合''与``逐点门控''两种融合形式，未穷举所有利用方式，故该结论的适用范围限于本文口径与形式，不作出一般性断言；
  \item \textbf{调整层与执行层尚未联合优化}：调整层按点预测求解确定性线性规划，未把剩余时段的预测不确定性纳入目标（如场景规划、机会约束）；执行层亦为逐区间规则，二者之间存在可改进的空间；
  \item \textbf{尚未建模的因素}：预测只使用历史实测，未利用气象预报、节假日日历等外生信息；分位裕量按各时段独立估计，未建模时段间相关性；电价固定，未考虑实时波动（问题四方向）。
\end{enumerate}
