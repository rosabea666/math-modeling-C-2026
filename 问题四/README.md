# Q4 v3：实时波动电价下重算 Q2/Q3（当前版本）

**唯一入口**：`python scripts/q4_model_v3.py --adjustment-rollout --out results/q4_v3`
（全量约 3 分钟；`--terminal-check` 终端归一化对照；独立核验
`python scripts/q4_check_v3.py results/q4_v3`）。本目录由脚本生成，勿手改。
评价期 2025-02-01~12-31（334 天）；1 月共同预热（TOU + 代表日，E(1/1)=6000），
评价期起点 SOC = 10800（两个分支相同）。

## v3 相对 v2 的修正（errata）

1. **日内价格信息泄漏修复**：v2 的日内残差用 `lev[d]`（当天全部 144 个价格的
   最小二乘水平）——含未来区间。v3 的 `prefix_features` 只用 τ 之前的前缀
   （正则化缩向 30 天先验），并通过"扰动未来电价、预测不变"的因果测试
   （3 天 × 4 时刻，diff=0）。修复后日内价格通道（G_price=1411.4533）仍略劣于
   TOU 决策价（G_fixed=1410.9389），原方向结论不变，但依据干净了。
2. **情景 LP 终端罚除以 S 修复**：v2 的 H0B 把末端罚放大了 30 倍。v3 的
   `scenario_plan` 改为情景平均并通过"复制情景目标不变"测试。但 v2"关闭情景
   规划"的结论**不能仅凭旧代码维持**——v3 改用执行规则一致的回放评分
   （feedback selector）重新检验，见下文负结果。
3. **"价格预知价值≈0"撤回**：v2 的价格全知参照（1414.3723）用的是**未重校准
   的裕量政策**，主方案低于它不构成有效证明。v3 在**同一 G11b 裕量政策**下
   重算：G_price_oracle = **1403.2359** ⇒ 价格预知的真实价值 = 1410.9389 −
   1403.2359 = **7.7030 万**。

## 主方案（v3 冻结）：48 小时滚动时域

**机制**：日前计划 LP 的优化终点从当日 24:00 延到次日 24:00。次日净负载与
电价用**持久性预测**（= 当日预测的平铺，不读次日实测）；次日的暂拟购电
不提交、不产生调整费；执行只取当日合同。调整时刻同样按"今日剩余 + 次日"
重解（`adjustment_48`：今日部分对计划净额收 0.5p 附加费，末端约束为次日末
回到今日起始 SOC）。效果是放松了 v2 的强制日循环 $E_H=E_0$——储能可以
跨午夜持有电量，只要（按预测）次日末回到循环点。

**终端归一化对照**（12/31 强制 E_end≥10800 重跑最后一天）证明收益不是
年末库存差异的伪影。**跨日持有是 v3 最大单项改进**（两分支合计 −17.78 万）。

## 严格费用下界

## 口径与局限

- **次日全知上界已测**：F_48o = 1435.2658 / G_48o = 1401.1517（次日净负载与
  电价用实测，非因果不可实施）——持久性平铺距理论上限仅 **2.96 / 3.09 万**，
  因果次日预测最多只能收回其中一部分，**方向据此关闭**（如实标注上界）；
- 48h 持久性预测（次日=当日预测平铺）是**明确声明的近似**；次日合同不提交，
  无信息泄漏；题面"当天购电策略"按滚动时域（MPC）解读——每日 0:00 只提交
  当日合同，与题意不冲突，但属于对 Q2/Q3"日循环"建模约定的放宽，已标注；
- 价格揭示口径（区间完成才可知）维持 v2 假设；
- 固定参数的选定仍为同年探索性，不是未触碰外部测试；
- 未做：跨周末/月末效应。
